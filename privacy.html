Politica de privacidade - ARSD rclone M4

Este aplicativo e usado somente pelo seu dono, com a propria conta Google.

  • Os dados do Google Drive sao acessados apenas pelo rclone, no computador do dono, para copiar e sincronizar arquivos do proprio dono.
  • Nenhum dado e coletado, vendido, compartilhado ou enviado a terceiros.
  • Os tokens de acesso ficam somente no computador do dono e podem ser revogados a qualquer momento em myaccount.google.com/permissions.

Uso de dados de APIs do Google em conformidade com a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
